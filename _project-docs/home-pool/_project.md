# Project: Home pool

## Description


## Instructions
In-ground saltwater pool in Hogansville, GA. 26,659 gallons, 18×36 ft with 3 ft shallow / 7.5 ft deep ends. Vinyl liner (4 years old), no main drain — surface skimming only. Sand filter. CircuPool RJ-series SWG (60,000 gal capacity, healthy cell). Mesh safety cover for off-season.
Surrounded by pines and oaks — heavy organic debris year-round. Well water source.
Owner manages chemistry directly using a Taylor K-2005/K-2006 test kit. Follows TFP (Trouble Free Pool) methodology: SLAM protocol for algae, FC/CYA ratio management, minimal chemical inputs. Avoids pool store “treatment programs” and unnecessary additives.
Core chemical inventory:
	•	Liquid chlorine (backup for SWG)
	•	Muriatic acid (pH down)
	•	Soda ash (pH up)
	•	Pool salt
	•	Granular CYA stabilizer
	•	Baking soda for TA when needed
Equipment notes:
	•	CircuPool SWG controller and cell
	•	Pool Shark cleaner
	•	Mesh safety cover with brass anchor screws (anti-seize applied)
	•	Liner bead occasionally pops out — manageable with rubber mallet
Travel pattern: extended absences require pool to run autonomously on SWG with Angie checking in. Considering keeping pool open year-round in Georgia climate with reduced winter pump runtime.
Use this project for: chemistry questions, dosing math, equipment troubleshooting, seasonal opening/closing procedures, maintenance scheduling, and avoiding the pool store upsell trap
