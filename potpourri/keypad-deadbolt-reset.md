# Keypad deadbolt battery change and reset

Scott changed the batteries in a keypad deadbolt and it stopped working; he didn't know the master code.
The lock was a generic keypad deadbolt (label with UC/MC/R button), not Kwikset as first identified.
He reset it (3 long beeps), and the default user code 1234 opened it.
He asked how to test that 0000 (old master code) is deleted.
