# Georgia depreciation addback set to $0

**Decided:** Manually changed TaxAct's Georgia depreciation addback from $14,539 to $0.

**Why:** Federal takes 100% bonus depreciation on the $15,104 and Georgia allows full Section 179 on it, so the deductions match and there is nothing to add back.

**Rejected alternatives:** Leaving TaxAct's automatic $14,539 addback, or using $340 (a figure based on the earlier 40% bonus plan).
