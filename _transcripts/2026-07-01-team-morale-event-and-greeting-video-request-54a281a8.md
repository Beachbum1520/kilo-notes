I'll keep the response straightforward without unnecessary formatting, just clear options he can act on.Quick reality check first: most corporate email caps attachments around 20–25 MB (Outlook is 20, Gmail 25). Getting a 200 MB video under that means roughly a 90% cut, which will noticeably hurt quality on a costume-party video you want to look good. So the cleaner move is usually a link rather than an attachment — but here are both paths.

**Best option — send a link instead**

You've got Google Drive connected. Upload the video there, set sharing to anyone-at-Blueprint-RF (or just Jady), and paste the link into the email. No size fight, no quality loss, and Jady clicks once to watch. Same works with OneDrive/SharePoint if that's your Cox stack. For a 200 MB file this is what I'd do.

**If you do want to compress it**

HandBrake (free, Windows/Mac) is the easy button:
- Open the video, pick the preset **"Fast 720p30"** (or 480p if you need it smaller)
- Under Video, set Quality to RF ~24–26 — higher RF = smaller file
- That'll typically drop a 200 MB clip to 15–30 MB depending on length

If you're comfortable at the command line and have ffmpeg:

```
ffmpeg -i input.mp4 -vf scale=-2:720 -c:v libx264 -crf 28 -preset slow -c:a aac -b:a 128k output.mp4
```

Bump `-crf` up (30, 32) for a smaller file, down (24) for better quality.

**Or I can just do it for you** — upload the video here and I'll compress it to whatever target size you want and hand it back. Only catch is a 200 MB upload can be slow, so the Drive link is probably still the faster route to actually getting this email out the door.
