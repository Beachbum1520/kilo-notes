 Good instinct — don't rely on the dealer to self-report against their own interest. Here's how to verify independently:

**1. GM Owner Portal — most reliable**
Go to my.chevrolet.com, create an account and register the VIN. GM's system will show every factory-installed option on that specific vehicle. If HUD hardware is in the build data it will show there.

**2. Window Sticker by VIN**
Go to www.chevrolet.com/shopping/research/window-sticker and enter VIN 1GNS6FK85TR258261. This pulls the original factory window sticker directly from GM — not the dealer's copy. If HUD was optioned it will be listed there.

**3. RPO Codes**
The glove box should have a sticker with RPO (Regular Production Option) codes — a list of 3-character codes for every option the vehicle was built with. The HUD option code on GM vehicles is **UHX**. If UHX is on that sticker, the hardware is in the truck and the dealer owes you a working HUD under warranty.

Start with the glove box RPO sticker — takes 30 seconds and gives you a definitive answer before you make any call.
