### CLAUDE (2026-09-07T20:32)
Yes, likely — VTech's CS5119 series handsets are designed to be interchangeable and expandable across the same product line. The CS5119 (1 handset) and CS5119-2 (2 handset) use the same base/handset technology, so the single CS5119 handset should register as an accessory handset to the CS5119-2 base, up to whatever max the system supports (usually 12 handsets on VTech DECT 6.0 systems).

One caveat: buy the single CS5119 as an accessory handset only if it's sold that way — some single-unit boxes include their own base station, which you wouldn't need since you'd already have the 2-handset system's base. Check the box for "accessory handset" or confirm compatibility via the model numbers before buying, since VTech occasionally has non-cross-compatible sub-series despite similar naming.
