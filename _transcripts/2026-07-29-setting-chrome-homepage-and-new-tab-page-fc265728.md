### CLAUDE (2026-07-29T15:09)
Three separate settings in Chrome that people often conflate:

**Home button / homepage** — Settings → Appearance → toggle on "Show home button," then pick either "New Tab page" or enter a custom URL. If the home button is off, the homepage setting does nothing.

**Startup pages** (what opens when Chrome launches) — Settings → On startup. Three options: New Tab page, continue where you left off, or a specific set of pages. This is independent of the homepage.

**New tab page** — Chrome does *not* let you set a custom URL here natively. Every new tab gets Chrome's built-in page (search bar + shortcut tiles). You can only customize its appearance via the "Customize Chrome" button in the bottom-right corner — background image, shortcut behavior, color theme.

If you want a specific site on every new tab, you need an extension (New Tab Redirect, Custom New Tab URL, or similar). Worth knowing the tradeoff: those extensions request permission to read and modify data on every page you visit, which is a lot of trust for cosmetic benefit. Most people are better served by making that site the homepage and using the home button, or just pinning it as a tab.
