# Paste-ready text in the target system's format

When Scott asks for text to paste into another system (LinkedIn, Workday, email), give the whole thing, ready to copy and paste, in a format that system accepts: plain text, bullet characters inline if needed, no formatted bulleted lists. When asked for "the entire thing", repeat the whole section, not just the changed part.

**Source:** VP Support Ops - Velocity, 2026-04-14
