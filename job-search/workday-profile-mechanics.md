# How Scott's Workday profile works

Scott believes Workday's Professional Profile page is built from what's entered in the other tabs.
The only statement option available was "Career Objective".
Workday's skill library has no "Net Revenue Retention" skill.
In Workday description fields, bullets have to be typed inline as the "•" character inside plain text, not as a formatted bulleted list, and without line returns (Scott adds the breaks himself).
