# One entry per company, with promotions noted in the description

**Decided:** Where Scott held several titles at one company, show one entry under the highest title covering the full date range, with the first line of the description noting the promotion. Applied to Interel (title field "President, Americas"; description opens "Promoted from Senior Vice President to President, Americas within one year."; the SVP entry was deleted and the start date moved to Mar 2021), GuestTek (title "President, Americas"; four roles described as a progression), and PCH (Scott asked for the PCH roles to go on a single timeline). The same approach was used on the resume, LinkedIn and Workday.

**Why:** Reads more cleanly and highlights the promotions without near-duplicate entries.

**Rejected alternatives:** Separate entries per title. Also a combined title line such as "President, Americas | Promoted from Senior Vice President, Americas" (rejected as clunky).

**Would revisit if:** unknown.
