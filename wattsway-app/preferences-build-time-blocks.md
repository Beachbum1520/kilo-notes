# Build in defined time blocks, not late-night tinkering

Build the tool in defined time blocks, not open-ended evenings; no "I'll just tweak one thing" at 11 PM, because it undermines deep sleep — the primary training variable of the year. The tool should serve training, not sabotage recovery.
