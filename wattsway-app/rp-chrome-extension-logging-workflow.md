# Use Claude in Chrome with a saved prompt to extract RP sessions

**Decided:** Scott asked for a reusable prompt to save for the Chrome extension. It reads RP workout pages and outputs text ready to copy into chat. He used it on his M1 day pages, and it became his way of passing RP data to Claude.

**Why:** RP has no API or export. Screenshots are a poor method, and Claude cannot read RP URLs directly.

**Rejected alternatives:** Screenshots. Direct link reading, which returned an empty page shell.

**Would revisit if:** RP gets an automated access path.

**Approx date:** June 2026

**Source:** Getting an Oura API key, 2026-06-08
