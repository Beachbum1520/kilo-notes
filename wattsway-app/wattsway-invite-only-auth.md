# WattsWay auth is invite-only

**Decided:** Supabase email/password auth with public sign-ups disabled; accounts created via Supabase invite, users accept at `/accept-invite` and sign in at `/login`. Scott is the first invited user (full_name "Scott Watts").

**Why:** Family-scale private app — no public self-signup.

**Rejected alternatives:** Public self-signup.

**Would revisit if:** unknown.

**Approx date:** June–July 2026
