# Supabase "auto expose new tables" is OFF

The WattsWay Supabase project has "auto expose new tables" turned off, so new tables need explicit grants to authenticated and service_role or PostgREST returns 404/permission-denied.

**Approx date:** July 2026

**Source:** Garmin activities migration SQL (unnamed attachment) — Importing Garmin data with FitnessSyncer, 2026-07-10
