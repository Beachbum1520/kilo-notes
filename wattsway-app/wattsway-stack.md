# WattsWay stack

React + Vite PWA (installable, service worker, manifest, mobile-safe layout); Supabase (Postgres with RLS, email/password auth, Deno edge functions); Vercel hosting (Vite preset, `npm run build`, output `dist`, SPA rewrites in vercel.json); domain wattsway.com; Node.js 20+.
Local dev on http://localhost:5173. The `wattsway` folder may live inside a `training-coach` repo.
Env vars: VITE_SUPABASE_URL, VITE_SUPABASE_ANON_KEY, VITE_WITHINGS_CLIENT_ID.
