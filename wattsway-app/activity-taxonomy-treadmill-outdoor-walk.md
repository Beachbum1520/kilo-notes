# Activity types: treadmill runs, outdoor runs and walks as separate categories

**Decided:** Treadmill runs are captured as treadmill runs and outdoor runs as outdoor runs ("etc. etc."). Scott added that running and walking activities should each have their own category. The final taxonomy implemented was breathing, strength, walk, run (outdoor), treadmill and generic.

**Why:** Scott wanted each kind of activity distinguished rather than lumped into "generic."

**Rejected alternatives:** Sending outdoor runs and walks to "generic."
