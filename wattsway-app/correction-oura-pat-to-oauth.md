# Oura connection moved from personal access token to OAuth

**What was wrong:** The initial WattsWay build connected Oura by pasting a personal access token in Settings.

**Correct version:** By July 10, 2026, Oura connections use an OAuth access token; personal access tokens are described as "legacy" (Oura retired PATs in Dec 2025, per his Oura Apps Script).

**Approx date:** July 2026

**Source:** Garmin activities migration SQL (unnamed attachment) — Importing Garmin data with FitnessSyncer, 2026-07-10
