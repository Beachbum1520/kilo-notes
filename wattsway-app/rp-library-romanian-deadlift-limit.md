# RP exercise library has only a single-leg RDL

In Scott's RP app, the only option under "Romanian Deadlift" was the Single Leg Romanian Deadlift.
With the Hamstrings/Glutes filter, the list included Stiff-Legged Deadlift (barbell) and Smith Machine Good Morning.
