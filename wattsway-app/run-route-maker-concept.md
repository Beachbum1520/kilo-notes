# Run route maker concept

**Decided:** Consider a run route maker: when traveling, open WattsWay, enter a number of miles, and it builds a route from his exact current location using Strava and/or Garmin heat map data (routes most used by others in the area), then sends it to his watch.

**Why:** Strava and Garmin both have this feature but neither is good — Garmin puts you on busy roads and routes blocked by walls and other obstacles; Strava can't build a route from exact current location and often wants him to go several hundred yards or more to start.

**Rejected alternatives:** None stated.

**Would revisit if:** Depends on whether Strava/Garmin expose heat map data via API.

**Approx date:** July 2026

**Source:** Watts Way Fitness App, 2026-06-12
