# Integrations in place from the beginning: Oura and Withings direct, Garmin via FitnessSyncer→Drive

**Decided:** Integrations should be in place from the beginning, via direct APIs where possible. Adopted: "Oura and Withings direct, Garmin via your existing FitnessSyncer→Drive pipe at launch."

**Why:** Wants direct API connections to Garmin Connect, Oura, and Withings if possible; if it needs to go via Google Drive, so be it.

**Rejected alternatives:** Direct Garmin API at launch (requires developer program approval).

**Would revisit if:** Garmin developer access becomes available.

**Approx date:** June 2026

**Source:** Watts Way Fitness App, 2026-06-12
