# Daily Oura sync must update the sheet, not reset it

**Decided:** The automated daily Oura run must only add or update the latest data. It must not clear or reset the Google Sheet each day.

**Why:** He wants the full history to stay in place while new data is added.

**Rejected alternatives:** A clear-and-rewrite approach that would wipe the history.
