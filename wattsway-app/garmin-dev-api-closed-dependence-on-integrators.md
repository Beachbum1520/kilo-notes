# Garmin developer API closed, so WattsWay depends on third-party integrators

Garmin's developer program is closed. Until Garmin opens it back up, Scott sees WattsWay as "at the mercy of other integrators" for Garmin data.
Scott raised the concern that each family user would need their own FitnessSyncer account, and asked whether a different data aggregator should be considered.
