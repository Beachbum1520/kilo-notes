# WattsWay dashboard and settings features (steps 1–3)

Dashboard: stat cards for latest HRV, resting HR, last night's sleep, weight; line charts for HRV, resting HR, sleep (deep-sleep overlay), weight + lean mass; 30/90/365-day range toggle; 7-day rolling average on HRV and weight; empty state points to /settings.
Settings: connect Oura and Withings (OAuth2), manual sync, connection status and last-sync time per provider.

**Approx date:** June–July 2026
