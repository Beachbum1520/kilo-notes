# TrainingPeaks run header format

Every run begins with "DAY:" on one line, then "Location – Workout Type – Duration / Distance" (e.g., "Thursday: / Treadmill – Aerobic Run – 45 min / 4.0 mi").
Always include the day, treadmill or outdoor, and both duration and distance; never use brackets; Sunday long runs are Outdoor; treadmill runs must include mph targets.
Deviations from Scott's formatting system are considered errors.
