# TrainingPeaks format needs a Title and a Description

Each TP workout needs two parts: a Title and a Description. Scott shared two examples.
Title: "Location – Type – Duration / Distance".
Description: segments written as "X min - Zone X (bpm | exact pace | exact mph)", followed by Notes. Mph is included for treadmill runs.
Don't deviate from this format.

**Source:** Weekly run data from travel week, 2026-05-25
