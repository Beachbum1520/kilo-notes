# RP extraction via Claude in Chrome

Scott uses a Claude in Chrome extension command (set up in a June 10 chat) that reads the RP Hypertrophy workout page and outputs the day's logged sets as plain text for pasting into the coaching chat.
He also uses an end-of-week handoff command ("Command 1") to summarize a week's chat for the next week's chat.
