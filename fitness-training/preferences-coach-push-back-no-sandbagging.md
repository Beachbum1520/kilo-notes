# Coach must push back and not sandbag

Push back where what Scott did conflicts with where he's going, and own the call; "I don't want to" doesn't move the coach. Do not sandbag — each week should be as productive as possible; call out changes needed in either direction (easier or harder). If unclear about anything when prescribing, ask clarifying questions rather than guess.
