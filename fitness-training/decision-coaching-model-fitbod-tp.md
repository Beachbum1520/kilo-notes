# Coaching model: Fitbod programs strength, Claude coaches, Scott populates TrainingPeaks

**Decided:** Fitbod gives Scott the strength workouts and he shares results with Claude. Claude provides extras on top and coaching feedback (go all out, leave some in reserve, weight progression suggestions). Claude provides the running schedule, progression, and feedback; Scott populates TrainingPeaks.

**Why:** Scott's stated division of labor.

**Rejected alternatives:** Claude programming strength sessions directly; switching apps.
