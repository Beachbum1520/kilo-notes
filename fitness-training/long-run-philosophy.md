# Long run philosophy

Split-load weekends preferred over excessive single long runs; long runs emphasize durability; fueling rehearsed; final segments sometimes faster; cadence focus late; HR drift monitored.
Typical structure: Z1 warmup → extended Z2 → optional Z3 progression → Z1 cooldown.
