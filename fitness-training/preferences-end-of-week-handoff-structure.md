# End-of-week handoff structure

The end-of-week handoff is a complete state summary, exhaustive on substance and tight on prose, output as plain text in one code block with no commentary, with these sections: (1) week just completed — prescribed vs. actual, every strength session with logged loads/reps/RIR, runs (distance, duration, HR, shoe), missed/modified sessions and why, plunge/sauna adherence; (2) current program state — meso name, next week/RIR, the 4-day split, every exercise with current working load, capped lifts and why; (3) body/recovery data — Oura, Withings, labs, with trends; (4) decisions made this week, stated as settled rules; (5) open items/next-week actions with dates; (6) corrections Scott made to the coach that week.

**Source:** W/C - 7/6 Weekly Coaching, 2026-07-05
