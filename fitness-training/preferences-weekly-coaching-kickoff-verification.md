# Weekly coaching kickoff: verify state before building

At the start of each weekly coaching chat, load project memory and chats, read the Armor Build Memory Card (current version), TrainingPeaks Format Card, and Shoe Rotation Card from the ATP Data Drive folder, then pull completed workouts, Oura, Withings, workout files, test data and planning docs from the "Scott Watts 2026 ATP Data" folder without waiting for uploads. Before anything else, state today's date, current phase, recovery status, strength block/meso and week, days to next race, and active travel, and echo back settled decisions and corrections from last week's handoff so Scott can confirm them. If a fact isn't in the handoff or a Drive card, say so and ask — do not reconstruct it from memory or guess.

**Source:** W/C - 7/6 Weekly Coaching, 2026-07-05
