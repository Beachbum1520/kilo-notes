# Two-command system for coaching threads

**Decided:** Use a "NEW THREAD START" command (includes the previous thread's name) once when opening a new thread, then the "WEEKLY KICKOFF" command at the start of each week inside the thread. Scott confirmed: "so i use the new thread start only for the new thread. and then the weekly kickoff at the beginning of each week in the thread?" — "Yup."

**Why:** He keeps one thread until full, so the new-thread command needs to find and read the previous thread; weekly kickoff handles each week.

**Rejected alternatives:** A single weekly kickoff with no previous-thread reference.
