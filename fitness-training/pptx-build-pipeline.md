# PPTX build and QA pipeline

PPTX creation via PptxGenJS on Node.js; cannot load/modify existing files, so edits require a full re-run.
Visual QA: PptxGenJS → LibreOffice PDF conversion → pdftoppm JPEG per slide.
Text extraction from uploaded PPTX via python -m markitdown.
