FitnessSyncer has two sides: build the data Source (access), then build "what to do with it" (e.g., send to Google Drive so Claude can see it).
The FitnessSyncer "Oura Sleep Data.csv" in Drive came from a FitnessSyncer sync that wasn't pulling historical data but seemed to pull good data going forward.
Scott thought he had checked "everything" in the API setup.
Oura is not listed as a source for the Temperature or Oxygen data types in FitnessSyncer. It is listed for Activity.
The Oxygen source dropdown defaulted to Apple Health.
The new Sleep source is named "Oura - Sleep - From FitnessSyncer." The Oura consent screen was accepted with all boxes checked. The historic sync range was set from 12/21/2023.
