# TrainingPeaks run block format

Each run segment: "X min - Zone X (HR bpm range | pace min/mi | exact treadmill mph)", e.g., "10 min - Zone 2 (133–148 bpm | 10:45/mi | 5.6 mph)".
HR and pace always included; treadmill workouts must include mph as a single exact midpoint number; never mph ranges or pace ranges; order must be HR | Pace | mph.
