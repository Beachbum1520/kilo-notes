# RP exercise note format

For RP workouts, give each exercise in this format so he can paste into the exercise notes for the week: "## lbs (estimated weight) - ## Reps (range is ok) - ## RIR - any notes or considerations" (form suggestions, use liquid chalk, change grips each hand, and other learnings as we progress). Quit making him guess (e.g., state how many sets).

**Source:** w/c 6-22 - weekly coaching discussion and feedback, 2026-06-23
