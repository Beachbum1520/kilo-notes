# Deep analysis, ask questions, verify memories

When asked for a deep analysis, take however long is needed and be detailed across all data sources (Oura, Withings, workout files, lab reports, test files).
Ask clarifying questions when needed.
Do not make assumptions.
Before relying on historical memories, check that they are still factual and relevant.
Cast as wide a data window as needed for the best analysis. "I want to get this right the first time."

**Source:** blood work analysis, 2026-06-21
