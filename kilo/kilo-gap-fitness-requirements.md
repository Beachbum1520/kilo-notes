# Gaps a replacement system must fill (fitness)

No live data pull by default; no time-series storage; no enforced pre-read; no severity/threshold schema for symptoms; no proactive check-ins; no persistent "this week's plan" object; no automatic reconciliation against memory.
Target: automatic Drive polling, a severity threshold table, and a persistent mutable weekly plan record.
