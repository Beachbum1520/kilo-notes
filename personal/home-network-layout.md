# Home network and house layout

Home internet is about 1 Gbps.
There are no Ethernet runs between node locations, so backhaul is wireless only.
There is no coax in the house.
The house is 4,000+ sq ft with a sprawling layout and drywall construction.
The router and demarc are in the center of the house. The plan is one mesh node on each side, toward the edges, with no daisy-chained hops.
Scott wants coverage to reach a bit outside, around the pool.

**Approx date:** July 2026
