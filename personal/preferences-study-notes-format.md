# Format for student study notes

Deliver the study notes as a Word document.
Remove every reference to "slide," the deck, or where the content came from.
Leave out the quiz, answer key, "how to use" section, and study-guide scaffolding. They should look like notes a student took while reviewing the slide deck.
Use the same format for every later deck, one document per deck.
If a deck duplicates one already done, skip it; if it's different, do it.

**Source:** Converting attachments to study notes, 2026-08-11
