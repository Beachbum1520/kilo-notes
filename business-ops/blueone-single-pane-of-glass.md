# Position the new BPRF customer dashboard as a single pane of glass

**Decided:** Scott pushed for the new customer dashboard to show every IP device on the BPRF managed network (STBs, thermostats, GRMS, minibars, IP phones, etc.) via API integrations, marketed as a true single pane of glass / fleet manager / total view of a property.

**Why:** That's what would make it disruptive; otherwise hoteliers will like it but it will be viewed as yet another of the many dashboards a hotel has to navigate.

**Rejected alternatives:** Positioning it only as a consolidated portal of BPRF property data.

**Would revisit if:** unknown

**Approx date:** May 2026

**Source:** BlueONE dashboard naming and marketing strategy, 2026-05-06
