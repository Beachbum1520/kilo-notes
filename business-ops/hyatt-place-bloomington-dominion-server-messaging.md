# Hyatt Place Bloomington "Dominion server" messaging issue

On network ticket #2040301 at Hyatt Place Bloomington, support sent a public-facing email saying the "Dominion Server is needed for monitoring purposes while the Nomadix Server was installed to handle the guest network."
This triggered pushback from the site's IT Director and corporate team, whose documentation shows a full upgrade to Nomadix.
