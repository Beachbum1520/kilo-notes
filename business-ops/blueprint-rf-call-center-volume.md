# Blueprint RF call center sizing

Blueprint RF runs on a cost-per-productive-hour model, so agent count varies.
Blueprint RF has between 35 and 45 agents taking about 10,000 calls a month.
Staffing need depends on each client's base and number of hotels.

**Approx date:** September 2026

**Source:** Negotiating return-to-office requirements, 2026-09-24
