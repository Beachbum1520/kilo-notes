# How the install forecast will be built

**Decided:** Add the install forecast to the capacity model. Take the current backlog, add a PWIN input variable that calculates the resulting number of install starts, and assume an even spread per month on a 90-day install timeline.

**Why:** Scott's TDEs lead all installs, so he has to forecast install starts too. He doesn't control the install team, which historically has given no more than a 2-week forecast.
