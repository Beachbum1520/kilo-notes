# Teams chat export constraints for install documentation

Cox's corporate retention policy on Teams chats is short.
Teams chats are the primary communication channel during installs, and the data is needed as part of the install documentation package — for every install.
Install chats run pages and pages, too many for screenshots.
Each install uses a separate Teams group chat, not a separate Teams channel.
Scott is an end user without elevated access; the enterprise won't change retention policy for his needs.
Browser print-to-PDF only captured one page even after scrolling to the top.
GoFullPage extension is not blocked on his machine.

**Approx date:** May 2026

**Source:** Exporting MS Teams chat for install documentation, 2026-05-26
