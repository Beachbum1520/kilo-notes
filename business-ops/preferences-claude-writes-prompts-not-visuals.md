# Use Claude to write prompts for other tools rather than to build visuals

Claude isn't strong at building visuals like PowerPoint slides but is good at writing prompts. For slide decks, write a prompt Scott can paste into Manus or ChatGPT to build the deck.
The prompt has to tell the other tool directly to combine the best of all sources into one finished deck, not just to "read" a document.

**Source:** Training prompt for Bo Schroeder's team, 2026-08-18
