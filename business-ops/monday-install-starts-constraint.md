# Monday-only install starts make the TDE-to-install ratio 1:1

The install team requested that all installs start on Mondays.
Before this, the TDE team was staffed for 7-day-a-week coverage with multiple install starts per week.
With all starts on Monday, the TDE-to-install ratio is 1:1. Under the install team's current schedule model, a TDE can support only one install at a time.
Marie confirmed the 12-install-starts-per-week figure is current post-close.
