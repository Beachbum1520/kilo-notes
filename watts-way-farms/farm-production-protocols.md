# Which production protocols apply

Pasture-raised, no antibiotics ever, no added hormones, and heritage breed apply to all Watts Way pork.
The same apply to beef, except heritage breed (the Dexters are not Duroc/Berkshire).
Scott does not do non-GMO, soy-free, or corn-free.
