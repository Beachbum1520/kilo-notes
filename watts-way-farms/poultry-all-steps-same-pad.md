# Do all poultry processing on the same pad

**Decided:** All processing steps (kill, scald, pluck, evisceration, packaging) will be done on the same pad, not in a separate area.

**Why:** Scott objected to a separate enclosed area adding cost.

**Rejected alternatives:** Separate enclosed structure for evisceration/packaging.

**Would revisit if:** GDA requires a separate enclosed area.

**Approx date:** September 2026

**Source:** Trump's executive order on farm meat processing, 2026-09-06
