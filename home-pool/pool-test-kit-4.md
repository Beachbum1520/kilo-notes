# Pool test kit

Leslie's Total Poolcare DPD Test Kit 18-576 (Taylor K-2005 equivalent; comparator block, not drop-count FAS-DPD).
Cannot measure CC accurately when FC >5 ppm (CC = TC − FC; both max out at SLAM levels). SLAM exit on this kit: overnight FC loss ≤1 ppm + visual clarity.
Reagents: R-0001/R-0002 FC; R-0003 Total Chlorine; R-0007/8/9 TA (×10); R-0010/11/12 CH (×10); R-0013 CYA in #9191/9197 tubes.
SLAM-level FC: dilute 1:1 with bottled water (not well water — iron interferes), multiply by 2.
Measuring CC at SLAM levels would need a K-2006 FAS-DPD kit.
